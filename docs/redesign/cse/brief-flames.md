# Codex image brief: blink and joy faces for the streak flames

Use your image generation tool (image_gen.imagegen) to EDIT the attached flame figures. Each attached image is one
of our streak flames in the Common Side Effects style, alone on a transparent canvas:
`docs/redesign/cse/split/flame-0.png` (0 days, ash and smoke), `flame-1.png` (first day), `flame-3.png` (3 days),
`flame-7.png` (7 days, thumbs up), `flame-30.png` (30 days, proud), `flame-comeback.png` (back after a break,
protecting an ember).

For the animation we need the SAME drawing with only the face changed. Keep everything else exactly as it is:
same canvas size, same figure position and scale, same body, flame shape, hands, feet, sparks, colours and line
work. Change only the eyes and mouth. Keep the real TRANSPARENT background (no backdrop, no checkerboard).

Make:
- a `blink` version of ALL SIX: the eyes closed as short relaxed curved lids, same mouth.
- a `joy` version of `flame-1`, `flame-3`, `flame-7` and `flame-30`: eyes squeezed into happy arcs and a small open
  smiling mouth, still in the series' understated deadpan way (a pleased grin, not a cartoon scream).

Save them as `docs/redesign/cse/flames/<name>-blink.png` and `docs/redesign/cse/flames/<name>-joy.png`, for example
`flame-7-blink.png`, `flame-7-joy.png`. Also copy each attached original unchanged to
`docs/redesign/cse/flames/<name>-idle.png`. Check that each edit has the same pixel size as its original and that
nothing outside the face changed. Do not modify any other files.
