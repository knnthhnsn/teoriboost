# Konkurrenceanalysen (Figma: UX-research → Konkurrentanalyse), omsat til TeoriBoost

Kilde: Kenneths Figma-fil, side "Konkurrentanalyse" (1 · Overblik, 2 · Dybdegående analyse), læst 21. okt 2026.
Konkurrenter: Teorikortet, Prove.dk, Teoriundervisning.dk, TeoriTjek (DK) og Drivly (NO).

## Hullet i markedet (positioneringskortet)
"Forstå + motivation til fair pris, dansk": læring og motivation, ikke kun prøve-realisme. Det er TeoriBoosts plads.
