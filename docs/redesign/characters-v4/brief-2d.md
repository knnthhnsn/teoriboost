# Codex image brief: redraw the Natkørsel cast in 2D

Use your image generation tool (image_gen.imagegen). For each of the 6 characters, use the existing 3D
image as the design reference (same character, same proportions, colours, signature features and
personality), and redraw it as a 2D illustration. Generate exactly 6 images and save each as
`docs/redesign/characters-v4/<slug>/hero-2d.png` (slugs: sneglen, kegle, blink, bobbel, krabbe, daek).
Reference images: `docs/redesign/characters-v4/<slug>/hero.png`. Do not modify any other files.
When done, list the saved file paths.

## 2D style (identical for all 6, so they read as one cast)
- Modern flat 2D vector mascot illustration for a mobile learning app, like a premium app mascot:
  clean bold shapes, smooth curves, simplified details.
- Flat colour fills with ONE level of soft cel shading (a single darker shadow shape per area) and a
  small highlight; no gradients, no 3D render look, no textures, no photorealism.
- Consistent dark outline in a deep indigo (#1E1B36), medium weight, slightly thicker on the outer
  silhouette.
- Big expressive eyes with a white highlight, readable at small sizes.
- Same pose and personality as the reference, full body, centred, strong readable silhouette.
- Plain flat cream background (#F6F3EE), no ground shadow except a small flat ellipse, no text,
  no logos, no license plates with text, no frame.
- Must not look like Pixar's Cars, Duolingo or any existing character.

## Characters (keep what makes each one work)
- sneglen: calm, sleepy-eyed snail whose shell is a small cream and deep-teal vintage camper car.
- kegle: nervous orange traffic cone with a white reflective stripe, hugging its stripe, sweat drop.
- blink: cheeky beetle with a glowing amber, faceted turn-signal shell, pointing to the side mid-hop.
- bobbel: eager mint-green bubble car, headlight eyes, chrome smile bumper, bouncing on its back wheels.
- krabbe: cocky coral-red hermit crab in a mustard-yellow toy car, claw resting out of the window.
- daek: friendly tyre coach with a silver rim face, bushy brows, winking, thumbs-up, walking.
