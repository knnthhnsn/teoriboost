# Codex image brief: Bobbel character model sheet (rig sheet)

Use your image generation tool (image_gen.imagegen). Use the two attached images:
1. `hero-2d.png` — Bobbel, our mascot (a mint-green bubble car with headlight eyes and a chrome smile bumper).
2. `reference-rigsheet.png` — a character model/rig sheet for a different character. Use it ONLY as the
   layout and method reference (turnaround + separated parts + expressions + poses). Do not copy that
   character.

Create ONE landscape image, 1536×1024, and save it as
`docs/redesign/characters-v4/bobbel/modelsheet.png`. Then make a second version with a plain white
background saved as `docs/redesign/characters-v4/bobbel/modelsheet-white.png`. Do not modify other files.

## Style
Bobbel simplified for animation, like the reference: flat colours with one soft shade, simple rounded
shapes, fewer chrome details, very readable. Keep it clearly the same Bobbel: mint-green (#8FC9A0) body,
cream (#F3E9C8) top, big headlight eyes, chrome smile bumper, small round wheels, two mirror stalks.
Background for the first version: dark slate (#2F3E46) like the reference. No text labels.

## Layout (three rows, like the reference)
- Row 1 — turnaround: Bobbel from the FRONT, from the SIDE (facing right) and from the BACK, same size.
- Row 2 — separated rig parts, each floating on its own: two eye sets (headlight eyes open; eyes with
  angry brows), a nervous eye set with sweat drops, a flat closed-eye set, three mouth/bumper shapes
  (smile, gritted teeth, small "o"), one mirror stalk "arm" in two poses (straight; bent waving with a
  little chrome hand / thumbs-up), and a pair of wheels as "feet".
- Row 3 — poses: laughing with one eye winking and leaning back on its rear wheels with sparkles;
  cool with black sunglasses, leaning back relaxed; cheering, both mirror "arms" raised.
