# Codex image brief: blink faces for the TeoriBoost cast (for the idle animation)

Use your image generation tool (image_gen.imagegen) to EDIT each attached cast figure. Each attached image is one of
our characters in the Common Side Effects style, alone on a 512 x 512 transparent canvas:
`docs/redesign/cse/blink/<name>-idle.png` for blink, bobbel, krabbe and daek.

For the animation we need the SAME drawing with only the eyes closed. Keep everything else exactly as it is: the same
canvas size, figure position and scale, body, pose, props, colours, line work and mouth; change only the eyes, drawn
closed as short relaxed curved lids in the same ink line (for Bobbel the car, close its headlight eyes the same way;
for Krabbe close the crab's eyes on their stalks; for Dæk close the eyes on the hubcap). Keep the real TRANSPARENT
background (no backdrop, no checkerboard). Save each as `docs/redesign/cse/blink/<name>-blink.png`, and check that
each has the same pixel size as its idle image and that nothing but the eyes changed. Do not modify any other files.
